Most assistive AI for blind people narrates every thing it sees.
That's not accessibility. That's noise.

I built Sentinel — a proactive, haptic co-pilot for people who can't see.

The difference? Sentinel stays silent.

🛡️ It watches the world for you
📳 It only intervenes when it matters
🔇 Everything else goes in the Silence Log — proof it chose not to disturb

Every alert is scored by how imminent, actionable, and non-redundant it is.
If it's not urgent enough to interrupt you, it doesn't.

Over 2.2 billion people worldwide live with vision impairment.
The assistive tech available today — Seeing AI, Lookout, Envision — all react.
Sentinel is designed to anticipate.

Built with:
→ Vanilla JS, zero dependencies
→ Web Audio spatial panning for directional haptics
→ Web Speech API for calm, minimal voice alerts
→ Real-time salience filtering (the brain of the system)

This is v0.1 — an early interactive prototype.
Next up: YOLOv8-nano for real object detection, MediaPipe for skeletal tracking, and MiDaS for depth.

Source code: https://github.com/sanju-zxt/sentinel-prototype
